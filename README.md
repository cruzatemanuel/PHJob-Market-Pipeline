An end-to-end Data Engineering & Analytics Pipeline built to collect, clean, standardize, analyze, and visualize tech and remote job postings in the **Philippine (PH) Job Market**.

## 💡 Key Features

- **Ingestion Engine (`src/scrape.py`)**: Collects job metadata including titles, salary ranges (PHP & USD), work setup (Remote, Hybrid, On-site), locations (Metro Manila, Cebu, Davao, Clark), and experience levels into timestamped raw JSON snapshots. Includes synthetic mock mode for reproducible offline testing.
- **Automated ETL Pipeline (`src/transform_load.py`)**:
  - **Currency Normalization**: Converts USD salaries to PHP equivalents (`USD_TO_PHP_RATE`).
  - **Regional Standardization**: Maps location strings to key PH hiring hubs.
  - **Taxonomy Skill Extraction**: Extracts programming languages, frameworks, cloud services, and soft skills using regex keyword matching.
  - **Dual Database Support**: Connects automatically to **PostgreSQL** or falls back seamlessly to lightweight **SQLite** (`ph_job_market.db`).
- **Data Visualizations (`src/generate_charts.py`)**: Produces 300 DPI charts in `charts/` detailing top demanded skills, salary distributions by experience level, work setup breakdown, and regional hiring volume.
- **SQL Analytics (`queries/analysis.sql`)**: Ready-to-run queries answering key tech career questions in the PH market.
- **Automated Test Suite (`tests/validate_load.py`)**: Verifies pipeline execution, schema integrity, and data transformations.

## ⚡ Quick Start

### 1. Prerequisites

- Python 3.9–3.12 (the pinned Playwright and PostgreSQL driver releases do not support Python 3.13)
- Docker & Docker Compose (Optional, for PostgreSQL container)

### 2. Environment Setup

Clone the repository and install Python dependencies:

```bash
git clone https://github.com/cruzatemanuel/PHJob-Market-Pipeline.git
cd PHJob-Market-Pipeline

# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install requirements
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
```

### 3. Database Options

#### Option A: PostgreSQL via Docker (Recommended for production)
```bash
docker-compose up -d
```

#### Option B: SQLite Fallback (Zero setup)
If PostgreSQL is not running, the ETL pipeline automatically uses `ph_job_market.db` with schema pre-initialized.

## 🚀 Running the Pipeline

### Step 1: Scrape / Ingest Job Data
Run the scraper module to fetch raw job listings and save a snapshot in `data/raw/`:

```bash
python src/scrape.py --mode mock --count 50
```

### Step 2: Transform & Load (ETL)
Parse the raw JSON snapshot, clean fields, extract skill keywords, and load records into the database:

```bash
python src/transform_load.py
```

### Step 3: Generate Market Visualizations
Query the database and render PNG charts in `charts/`:

```bash
python src/generate_charts.py
```

Generated charts will appear in the `charts/` folder:
- `top_demanded_skills.png`
- `salary_by_role_experience.png`
- `work_setup_distribution.png`
- `hiring_hubs_map.png`

## 📊 SQL Analytics Suite

Execute `queries/analysis.sql` using PostgreSQL (`psql`) or SQLite command-line tool.

Sample Query: Top Highest-Paying Tech Skills in PH Market
```sql
SELECT 
    s.skill_name,
    s.category,
    COUNT(js.job_id) AS job_sample_size,
    ROUND(AVG(j.salary_php_equiv), 2) AS avg_skill_salary_php
FROM skills s
JOIN job_skills js ON s.skill_id = js.skill_id
JOIN jobs j ON js.job_id = j.job_id
WHERE j.salary_php_equiv IS NOT NULL
GROUP BY s.skill_id, s.skill_name, s.category
HAVING COUNT(js.job_id) >= 2
ORDER BY avg_skill_salary_php DESC
LIMIT 10;
```
